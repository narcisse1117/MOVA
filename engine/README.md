# engine: 대중교통 경로 탐색 (RAPTOR)

`prep/`의 결과(`prep/out/`)를 읽어 지하철+버스 경로를 찾고, 택시 직행·대중교통만·대중교통+택시 조합을 비교한다 (F1, F2).

## 실행

```
pip install pandas numpy scipy
python engine/cli.py --from 홍대입구 --to "잠실(송파구청)" --time 23:30
python engine/cli.py --from 37.5665,126.9780 --to 37.6543,127.0568 --time 00:10 --day SAT
```

- `--from`, `--to`: 역 이름(앞부분만 같아도 됨) 또는 `위도,경도`
- `--time`: 03시 이전은 전날 운행일의 24시 이후로 본다 (`00:10` → 24:10)
- `--day`: `WD`(평일, 기본), `SAT`, `HOL`
- 처음 실행할 때 노선망을 만들어 `engine/cache/`에 저장한다 (약 40초). `prep/out/` 파일이 바뀌면 다시 만든다. `--rebuild`로 강제로 다시 만들 수 있다

## 구조

| 파일 | 하는 일 |
|---|---|
| `network.py` | 지하철 정차 순서가 같은 열차끼리 노선으로 묶고, 버스는 가상 운행을 만든다. 환승 도보 연결을 붙인다 |
| `raptor.py` | `query()` → 탈것 수(1~3)별 가장 빠른 대중교통 경로. `plan()` → 택시 직행 / 대중교통만 / 조합(추천 + 다른 안 최대 2개). `describe_plan()`으로 글로 바꾼다 |
| `fares.py` | 택시 시간·요금 추정, 대중교통 요금. 숫자는 `config/fares.json`에서 읽는다 |
| `cli.py` | 시험용 명령 |

## 규칙

- **탈것 최대 3번** (대중교통 환승 2번). 결과는 탈것 수가 늘 때 도착이 5분 이상 빨라지는 경로만 남긴다
- **버스 가상 운행:** 기점 막차 시각에서 평균 배차 간격씩 거슬러 올라가며 첫차까지 만든다. 정류장 시각은 그 시각대의 구간 운행시간(중앙값)을 더해 구한다. 막차는 정확하지만, 그 전 버스는 실제로 배차 간격만큼 어긋날 수 있다 (결과에 배차 간격을 같이 보여준다)
- **공식 정류장별 막차·첫차** (`데이터/bus_stop_times_*_<요일>.csv`가 있을 때): 막차와 첫차는 공식 시각에 맞추고, 그 사이 버스는 공식 시각에서 2시간 안이면 공식 쪽으로 보정한다
  - 튀는 값 거르기: 정류장 순서대로 시각이 늘어나는 값을 가장 많이 남기고(최장 증가 부분수열), 정류장별로 거꾸로 구한 기점 시각의 중앙값에서 30분 넘게 벗어난 값은 버린다
  - 기점 막차·첫차가 공식 값과 10분 넘게 어긋나면 공식 쪽에서 거꾸로 구한다 (예: 1227번 기본정보 막차 25:00 → 공식 23:20쯤)
  - **단축 운행:** 공식 막차보다 3분 넘게 늦게 지나는 운행은 그 정류장에서 타고 내릴 수 없게 막는다 (이웃 정류장도 같이 이를 때만). 없는 버스를 안내하지 않기 위해서다
  - 결과 (HOL, 정류장 36,854곳): 엔진 막차가 공식보다 3분 넘게 늦은 곳 0.8%(대부분 3212번), 3분 넘게 이른 곳 2.8%
- **가상정류장**(도로 위 측정 지점, 110개)은 타고 내릴 수 없어서 노선에서 빼고 시간만 남긴다
- **2호선 순환:** 데이터는 성수에서 한 바퀴 단위로 운행이 끊겨 있다. 성수에 도착한 운행에 3분 안에 같은 방향으로 출발하는 운행을 이어 붙인다
- **갈아타기 시간:** 같은 역(place_id) 안 180초, 같은 정류장 30초, 그 밖은 `transfers.csv`의 걷는 시간
- **출발·도착 걷기:** 직선 800m 안의 역·정류장. 직선거리 × 1.3 ÷ 1.1m/s, 역은 승강장까지 120초를 더한다
- 지하철은 `quality`가 `ok`, `dep_from_arr`인 열차만 쓴다 (1호선 경인 구간 suspect 열차는 빠짐)
- 한강버스(선박)는 뺀다

## 택시와 요금 (`config/fares.json`)

- **택시 요금:** 서울 중형택시 공식 요금 (2023-02 시행, 서울시 교통 누리집 2026-10-14 수정본으로 확인). 주간 1.6km 4,800원·131m당 100원, 22~23시·02~04시 5,800원·120원, 23~02시 6,700원·140원. 시간 요금은 저속 구간 비율(12%)로 근사, 100원 단위 반올림. 탄 시각의 요금대를 끝까지 쓴다고 가정
- **택시 거리·시간 (추정):** 직선거리 × 1.35 (범위 1.2~1.55), 시간대별 속도(22시 24km/h ~ 02시 35km/h), 호출 대기(23~01시 10분). **네이버 Directions 5 키가 나오면 `fares.taxi_trip()`만 바꾼다**
- **대중교통 요금 (확인 필요):** 지하철 1,550, 간선·지선 1,500, 마을 1,200, 심야 2,500, 광역 3,000원. 통합환승은 탄 것 중 가장 비싼 기본요금 + 10km 초과 5km마다 100원. 2026 하반기 300원 인상안이 있어 다시 확인해야 한다
- **조합 후보:** 대중교통으로 닿은 모든 역·정류장에서 도착지까지 택시 (도착지 1km 안은 제외). 역에서 내리면 지상까지 2분을 더한다
- **조합 추천:** 택시비 + 200원/분 × 걸린 시간이 가장 작은 것. 다른 안은 도착 시각·택시비의 파레토 후보 중 가장 빠른 것과 가장 싼 것 (추천과 2,000원 또는 10분 넘게 다를 때)
- **조합을 안 보여주는 경우:** 택시 직행보다 3,000원(또는 20%) 넘게 싸지 않거나, 대중교통만보다 5분 넘게 빠르지 않을 때

예시 (평일 00:30 홍대입구 → 노원):

| 방법 | 도착 | 요금 |
|---|---|---|
| 택시 직행 | 01:23 (53분) | 29,100원 (26,400~32,700) |
| 대중교통만 | 02:03 (93분) | 2,900원 (271 → N61) |
| 조합 추천 | 01:47 (77분) | 9,650원 (2호선 → 142번 → 택시 2.7km) |
