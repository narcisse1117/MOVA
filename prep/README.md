# prep: 지하철 데이터 정리

국가철도공단 파일 두 개를 경로 엔진이 쓸 표로 바꾼다.

## 입력 (상위 폴더 또는 `데이터/` 폴더에 둔다)

- `전체_도시철도운행정보_*.xlsx`: 열차번호, 정거장별 도착·출발 시각
- `전체_도시철도역사정보_*.xlsx`: 역 좌표, 환승, 운영기관

## 실행

```
pip install pandas openpyxl
python prep/parse_rail.py
```

1~2분 걸린다. 결과는 `prep/out/`에 생긴다.

## 출력

| 파일 | 내용 |
|---|---|
| `stop_times.csv` | 열차(trip_id)·정거장(seq)별 `arr_sec`, `dep_sec`. 운행일 기준 초라서 자정 이후는 86400(24:00)을 넘는다. `service_days`는 WD/SAT/HOL. `place_id`로 역을 찾는다 |
| `stations.csv` | 역사정보 + `place_id`(같은 이름, 700m 안 = 한 장소 = 환승역) + `coord_suspect`(주소와 좌표가 안 맞음) |
| `name_aliases.csv` | 운행정보의 역 이름 → 장소 대응. `needs_review=True`는 사람이 확인 |
| `report.txt` | 노선별 열차 수, 기준일, 평일 마지막 출발, 품질 문제 목록 |

`manual_aliases.csv`에 코레일 줄임말(예: `디엠시` → 디지털미디어시티)을 직접 적는다. 전부 '추정'이니 확인 후 status를 바꾼다.

## 처리 규칙

- 형식 세 가지를 읽는다: 정거장마다 한 줄(코레일), 열차 한 줄에 `001-성수+002-뚝섬`(서울교통공사 등), 쉼표 구분(7호선 연장 구간)
- `00:00`은 빈 값 표시로 본다. 03시 이전 시각은 전날 운행일의 연장(24시 이후)으로 바꾼다 (신분당선·9호선은 자정 이후를 `00:10`으로 적는다)
- 같은 열차가 서울교통공사 형식과 코레일 형식에 모두 있으면 서울교통공사 형식을 남긴다. 단, 그쪽이 suspect면 코레일 형식을 남긴다
- 정차역 절반 이상이 천안 이남인 열차(대구권 광역철도 등)는 뺀다

## quality 값

| 값 | 뜻 | 엔진에서 |
|---|---|---|
| `ok` | 문제 없음 | 사용 |
| `suspect_geo` | 좌표로 본 이동 속도가 130km/h를 넘음. 역 이름과 시각이 어긋난 열차 | 쓰지 않거나 검증 후 사용 |
| `suspect_arr`, `suspect_order` | 도착/출발 시각 순서가 맞지 않음 | 위와 같음 |
| `dep_from_arr` | 출발 시각이 거꾸로 적혀 도착 시각으로 대신함 (신림선 일부) | 사용 (정차 시간 오차 1분 이내) |

## 알려진 문제 (2026-06-30 파일 기준)

- **1호선 경인 구간(구로~인천)**: 서울교통공사 형식 일부 열차의 역 이름이 시각과 어긋나 있다. suspect_geo 295개가 남아 있다 (코레일 형식으로 대신할 수 있는 161개는 바꿨음). 서울 안의 구일·개봉·오류동·온수가 영향을 받는다
- **양원역(경의중앙선)**: 역사정보 좌표가 경북으로 잘못 들어 있다. 직접 고쳐야 한다
- **데이터 기준일**: 우이신설선 2022-05, 신림선 2025-09, 서울 1~8호선 2025-12. 막차 몇 개를 운영사 안내와 대조해야 한다
- **GTX-A**: 파일에 없다
